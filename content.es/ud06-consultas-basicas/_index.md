# UD06 · Consultas sobre una tabla y funciones

Con la base de datos creada y cargada, empezamos a **extraer información**. Esta unidad presenta la sentencia `SELECT` sobre una tabla: proyección, selección, ordenación, valores nulos y las funciones de fila de Oracle. Todo se practica sobre los datos reales del proyecto EduGest, con los resultados esperados para que puedas comprobar cada consulta.
