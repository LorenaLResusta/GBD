# UD05 · Manipulación de datos, transacciones y PL/SQL

Hasta aquí la base de datos solo se ha creado y consultado. Ahora **cambia**: se insertan, modifican y borran filas, y esos cambios deben ser seguros aunque varios usuarios trabajen a la vez (transacciones, ACID, bloqueos). Cuando una regla de negocio no cabe en una sentencia, se programa **dentro del servidor** con PL/SQL: procedimientos, funciones, cursores, excepciones y disparadores.
