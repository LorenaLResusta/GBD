# Tema 2 · Diseño lógico de bases de datos

Este tema desarrolla el **RA2** del módulo.

{{< ra "RA2" >}}

El tema se divide en las partes siguientes, cada una con su teoría y sus prácticas:

| Parte | Teoría | Prácticas |
|---|---|---|
| **Modelo Entidad/Relación** · Ciclo de diseño, entidades, atributos, relaciones, cardinalidades, entidades débiles, jerarquías, notaciones, herramientas y caso EduGest | [Teoría](/tema2-diseno-logico/er-teoria) | [Prácticas](/tema2-diseno-logico/er-practicas) |
| **El modelo relacional** · Relaciones, dominios, claves, `NULL`, integridad, reglas de transformación E/R → relacional, restricciones no representables y caso EduGest | [Teoría](/tema2-diseno-logico/relacional-teoria) | [Prácticas](/tema2-diseno-logico/relacional-practicas) |
| **Normalización** · Anomalías, dependencias funcionales, claves, 1FN, 2FN, 3FN, FNBC, descomposición sin pérdida y desnormalización | [Teoría](/tema2-diseno-logico/normalizacion-teoria) | [Prácticas](/tema2-diseno-logico/normalizacion-practicas) |
