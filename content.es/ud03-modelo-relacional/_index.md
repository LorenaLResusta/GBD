# UD03 · El modelo relacional

El modelo relacional es el puente entre el diseño conceptual y la base de datos real. En esta unidad estudiarás sus elementos (relaciones, claves, restricciones) y aprenderás a transformar sistemáticamente un diagrama Entidad/Relación en un conjunto de tablas listo para implementarse.
