# UD10 · Bases de datos no relacionales (NoSQL)

Ahora que dominas el modelo relacional, es el momento de conocer las alternativas y, sobre todo, de aprender a **elegir**. Esta unidad caracteriza los tipos de bases de datos NoSQL y trabaja en profundidad una base de datos documental, **MongoDB 8.0**, con una versión documental de EduGest que permite comparar resultado a resultado con Oracle.
