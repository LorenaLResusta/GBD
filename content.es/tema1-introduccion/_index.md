# Tema 1 · Sistemas de almacenamiento y SGBD

Este tema desarrolla el **RA1** del módulo.

{{< ra "RA1" >}}

Antes de escribir una sola línea de SQL hay que entender **qué problema resuelve una base de datos** y por qué existen los sistemas gestores. Este tema da la visión global del módulo: cómo se almacenaba la información antes de los SGBD, cómo funciona un SGBD por dentro, qué funciones y componentes tiene y cómo se clasifican.
