# UD06 · Consultas: de una tabla a varias

Con la base de datos creada y cargada, empezamos a **extraer información**. La unidad se divide en dos partes: primero la sentencia `SELECT` sobre una tabla (proyección, selección, ordenación, nulos y funciones de fila de Oracle) y después la información repartida entre varias tablas: `JOIN`, agrupamientos, subconsultas, conjuntos, vistas y optimización. Todo se practica sobre los datos reales del proyecto EduGest, con los resultados esperados para que puedas comprobar cada consulta.
