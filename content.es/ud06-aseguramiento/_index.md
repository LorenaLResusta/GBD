# UD06 · Aseguramiento de la información y bases de datos NoSQL

Una base de datos que no se puede recuperar no es fiable. Esta unidad trata las **copias de seguridad y su restauración**, la **importación y exportación** de datos y la transferencia entre gestores, y cierra el módulo con una introducción a las **bases de datos no relacionales** con MongoDB, comparadas siempre con el modelo relacional.
