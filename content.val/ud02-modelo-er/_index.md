# UD02 · Model Entitat/Relació

El disseny d'una base de dades comença **lluny de l'ordinador**: escoltant el client i representant la realitat amb un model conceptual. En esta unitat aprendràs a transformar un enunciat en un diagrama Entitat/Relació estés, a justificar cada decisió i a documentar el que el diagrama no pot expressar.
