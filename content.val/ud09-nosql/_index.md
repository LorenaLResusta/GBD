# UD09 · Bases de dades no relacionals (NoSQL)

Ara que domines el model relacional, és el moment de conéixer les alternatives i, sobretot, d'aprendre a **triar**. Esta unitat caracteritza els tipus de bases de dades NoSQL i treballa en profunditat una base de dades documental, **MongoDB 8.0**, amb una versió documental d'EduGest que permet comparar resultat a resultat amb Oracle.
