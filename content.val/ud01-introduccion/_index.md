## Tema 1 · Sistemes d'emmagatzematge i SGBD

Abans d'escriure una sola línia de SQL cal entendre **quin problema resol una base de dades** i per què existixen els sistemes gestors. Este tema dona la visió global del mòdul: com s'emmagatzemava la informació abans dels SGBD, com funciona un SGBD per dins, quines funcions i components té i com es classifiquen.
