# UD01 · Sistemes d'emmagatzematge i SGBD

Abans d'escriure una sola línia de SQL cal entendre **quin problema resol una base de dades** i per què existixen els sistemes gestors. Esta unitat dona la visió global del mòdul: com s'emmagatzemava la informació abans dels SGBD, com funciona un SGBD per dins, quins tipus n'hi ha, com es distribuïxen les dades i quines obligacions legals té qui les tracta.
