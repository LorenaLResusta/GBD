# UD03 · El model relacional

El model relacional és el pont entre el disseny conceptual i la base de dades real. En esta unitat estudiaràs els seus elements (relacions, claus, restriccions) i aprendràs a transformar sistemàticament un diagrama Entitat/Relació en un conjunt de taules llest per a implementar-se.
